Автор тоже начинает с нуля. Каждый этап будет расписан понятным языком.

🔗 Паблик: https://vk.com/ai_bez_b

## Запуск
1. `cp .env.example .env`
2. Заполните `.env` необходимыми ключами (см. ниже)
3. `pip install -r requirements.txt`
4. `python main.py` — создать и опубликовать пост
5. `python main.py test` — создать пост без публикации

## Переменные окружения
Обязательные:
- `SERVERSPACE_BASE_URL` — базовый URL API LLM-провайдера
- `SERVERSPACE_API_KEY` — ключ доступа к LLM API
- `VK_TOKEN` — токен доступа VK API
- `VK_GROUP_ID` — ID группы VK

Опциональные:
- `DAILY_BUDGET_RUB` — дневной лимит расходов на LLM (по умолчанию 100₽)
- `ATTACH_IMAGES` — прикреплять изображения к постам (true/false, по умолчанию false)

## Основные команды
- `python main.py` — создание и публикация поста
- `python scheduler.py` — запуск планировщика (посты в 13:00 и 19:00)
- `python run_stats.py` — ручное обновление метрик
- `python run_report.py` — публикация недельного отчёта
- `python check_api.py` — проверка доступности LLM API

## Правила проекта
Бюджет ≤ 3000₽/мес. Ключи только в .env. Никакой магии — только логи.

## Troubleshooting
### Ошибка "Все модели легли"
- Проверьте `SERVERSPACE_BASE_URL` и `SERVERSPACE_API_KEY`
- Убедитесь, что модели доступны в панели провайдера

### Ошибка VK API
- Проверьте `VK_TOKEN` и `VK_GROUP_ID`
- Убедитесь, что токен имеет права на публикацию и загрузку фото
- VK может ограничивать частоту запросов — реализована retry-логика

### Проблема с изображениями
- Убедитесь, что установлен пакет `pillow`
- Для кроссплатформенных шрифтов установите `dejavu-sans` (Linux) или используйте Windows/macOS

## Логирование
Все события логируются с временными метками. Логи включают:
- Ответы LLM моделей
- Расходы бюджета (с предупреждением при 80% лимита)
- Ошибки VK API с retry-попытками
- Ротацию старых записей (>90 дней)
