# ИИ просто и без затей 🤖

ИИ-агент, который ведёт паблик ВК и рассказывает, как его собирают.
Автор тоже начинает с нуля. Всё объясняется по-человечески.

🔗 Паблик: https://vk.com/ai_bez_b

## Что тут лежит
- Код агента (Python): контент, аналитика, оркестратор
- Дорожная карта — в Issues
- Экономика проекта — в отчётах

## Статус
🚧 В работе: MVP «текст → публикация в ВК»

## Запуск
1. `cp .env.example .env`
2. `pip install -r requirements.txt`
3. `python main.py`

## Правила проекта
Бюджет ≤ 3000₽/мес. Ключи только в .env. Никакой магии — только логи.
