# ИИ без затей — агент, который ведёт паблик ВК

ИИ-агент, который сам ведёт паблик ВК и рассказывает, как его собирают.
Автор тоже начинает с нуля. Каждый этап будет расписан понятным языком.

🔗 Паблик: https://vk.com/ai_bez_b

## Что нового в этой ветке

- **Починена публикация картинок в ВК.** Загрузка фото идёт двумя путями: «парадная дверь» — wall-загрузка (`photos.getWallUploadServer`) под личным бессрочным токеном пользователя, и запасная калитка — messages-загрузка под групповым токеном. Перед отправкой картинка автоматически пересжимается в лёгкий JPEG 1280px — ВК глотает его без вопросов.
- **Картинки стали фирменными.** Основной «художник» — Recraft v4.1 через GPTunneL: генерирует с опорой на брендовый образец стиля (`template/brand_bg.png`), промпт автоматически переводится на английский, цена проверяется **до** заказа (потолок 10₽ за картинку).
- **Три ступени на случай беды.** Recraft не ответил → бесплатный Pollinations → запаска на Pillow: заголовок на фирменном фоне за 0₽. Пост выйдет с картинкой в любом случае.
- **Картинки — в общий бюджет.** Траты на Recraft пишутся в тот же журнал расходов (`data/budget.db`) и упираются в тот же дневной лимит (`spend_fixed`).
- **Обновлена сетка моделей.** Убрали `gpt-5.4-mini`, планировщик и редактор теперь работают на Qwen3 Next 80B.
- **Новые диагностические скрипты:** `checkgpttunnel.py` (каталог медиа-моделей GPTunneL с ценами), `check_ref.py` (почему Recraft не берёт референс), `test_img.py` (сравнение картинки с референсом и без).

## Как это работает

Конвейер: **тема → исследование → черновик → критик → редактор → картинка → публикация**.

```
content_plan.json ──► Планёр ──► Исследователь ──► Писатель ──► Критик ──► Редактор
                      (тема)      (метафора, миф)   (пост)      (OK/FIX)   (шлифовка)
                                                                                        │
                              Художник (Recraft → Pollinations → Pillow)  ◄────────────┘
                                                                                        │
                              Публикатор ВК (wall-путь → messages-путь)  ◄────────────┘
```

- Рубрики по дням недели: Пн «AI с нуля», Вт «Практика», Ср «Инструмент», Чт «Словарь», Пт «Эксперимент», Сб «Кейсы», Вс — выходной.
- Критик сказал `FIX` — писатель переписывает. Только после `OK` текст идёт в редактуру.
- Бюджет-гард считает каждый токен и каждую картинку; при пробитии дневного лимита машина стоп.

## Подключение агентов с нуля

Весь конвейер держится на трёх внешних API: **LLM для текста**, **генератор картинок** и **VK API для публикации**. Ниже — путь от пустой папки до работающего агента.

### Шаг 0. Репозиторий и Python

```bash
git clone https://github.com/E-Tee/ai-bez-b.git
cd ai-bez-b
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Нужен Python 3.11+.

### Шаг 1. LLM для текста — Serverspace

Текстовые агенты (планёр, писатель, критик, редактор) ходят в OpenAI-совместимый API.

1. Зарегистрируйтесь по партнёрской ссылке: [https://serverspace.ru/ref/909496](https://serverspace.ru/ref/909496)
2. В панели создайте API-ключ для LLM и пополните баланс.
3. Скопируйте **базовый URL** OpenAI-совместимого эндпоинта (заканчивается на `/v1`) и **ключ**.
4. Проверьте, какие модели вам доступны: положите ключ в `.env` (шаг 4) и запустите `python check_api.py` — он выведет список моделей из `/models`. Точные ID моделей должны совпадать с каталогом.

### Шаг 2. Картинки — GPTunneL

«Художник» конвейера — модель `recraftv4_1` через медиа-API GPTunneL (CreativeLab API, `https://gptunnel.ru/api/v2/media`).

1. Зарегистрируйтесь по партнёрской ссылке: [https://gptunnel.ru/?ref=68e46fa120cfec0001649325](https://gptunnel.ru/?ref=68e46fa120cfec0001649325)
2. Пополните баланс и создайте API-ключ.
3. Ключ кладём в `.env` как `GPTUNNEL_API_KEY` (шаг 4).
4. Посмотреть каталог медиа-моделей и цены: `python checkgpttunnel.py`.

Каждый запрос к Recraft сначала проходит прайс-чек: если картинка дороже 10₽ — агент отказывается и падает на запасные варианты (Pollinations, затем Pillow-шаблон). Так что уйти в минус не получится.

### Шаг 3. VK API

1. Создайте сообщество ВК (тип «Паблик») — его и будет вести агент.
2. **Групповой токен** (`VK_TOKEN`): Управление сообществом → Работа с API → Ключи доступа → Создать новый ключ. Правки: **Wall** (стена) и **Photos** (фотографии). Этот токен умеет постить текст и ходить в messages-путь загрузки фото.
3. **Личный токен пользователя** (`VK_USER_TOKEN`, опционально, но рекомендуется): получается через Implicit Flow с правами `wall, photos, offline` (бессрочный). Именно он открывает «парадную дверь» загрузки фото — `photos.getWallUploadServer`. Нет его — агент сам перейдёт на messages-путь под групповым токеном.
4. **ID группы** (`VK_GROUP_ID`): числовой ID сообщества (в адресной странице или через любую «узнать ID ВК»).

### Шаг 4. Файл `.env`

```bash
cp .env.example .env
```

| Переменная | Обязательна | Что это |
|---|---|---|
| `SERVERSPACE_BASE_URL` | ✅ | Базовый URL OpenAI-совместимого LLM API (Serverspace, шаг 1) |
| `SERVERSPACE_API_KEY` | ✅ | Ключ LLM API (шаг 1) |
| `VK_TOKEN` | ✅ | Групповой токен ВК (шаг 3) |
| `VK_GROUP_ID` | ✅ | Числовой ID сообщества ВК |
| `GPTUNNEL_API_KEY` | для картинок | Ключ GPTunneL (шаг 2). Без него агент сразу идёт в бесплатные запаски |
| `VK_USER_TOKEN` | рекомендуется | Личный бессрочный токен для wall-загрузки фото (шаг 3) |
| `DAILY_BUDGET_RUB` | нет | Дневной лимит расходов на LLM + картинки (по умолчанию 100₽) |
| `GT_STYLE_REF` | нет | Публичная ссылка на образец стиля для тестов Recraft (`test_img.py`, `check_ref.py`) |

### Шаг 5. Проверка всех агрегатов

```bash
python check_api.py        # LLM API жив? Какие модели доступны?
python checkgpttunnel.py   # GPTunneL доступен? Цены на медиа-модели?
python test_img.py         # Recraft рисует? Сравни с референсом и без
python main.py test        # Полный конвейер БЕЗ публикации — пост печатается в консоль
python test_photo.py       # ВК принимает картинку (пост «проверка связи» в паблик)
```

### Шаг 6. Запуск

- `python main.py` — один цикл: создать и опубликовать пост.
- `python scheduler.py` — планировщик на локальной машине: посты в 13:00 и 19:00, метрики в 22:00, отчёт в воскресенье 18:00.
- **GitHub Actions** (без своего сервера): workflows в `.github/workflows/` уже настроены — пост ежедневно в 12:00 МСК, метрики в 22:00 МСК, отчёт по воскресеньям в 18:00 МСК. Занесите в Secrets репозитория те же переменные: `SERVERSPACE_BASE_URL`, `SERVERSPACE_API_KEY`, `VK_TOKEN`, `VK_GROUP_ID`, `GPTUNNEL_API_KEY`, `VK_USER_TOKEN`, `DAILY_BUDGET_RUB`.

После публикации агент коммитит обновлённый `content_plan.json` (тема помечается опубликованной). Запускаете локально — закоммитьте и запушьте план сами.

## Модели по агентам

Каждой роли — своя модель. Упала основная — автоматом берётся запасная (`agent/llm.py`).

| Агент (роль) | Чем занимается | Основная модель | Запасная |
|---|---|---|---|
| **Планёр** (`planner`) | Тема поста, если план иссяк; подбор визуальной метафоры; перевод промпта на английский | `qwen/qwen3-next-80b-a3b-thinking` | `deepseek/deepseek-v4-flash` |
| **Исследователь** (роль `planner`) | Метафора + бытовой пример + миф + применение по теме | `qwen/qwen3-next-80b-a3b-thinking` | `deepseek/deepseek-v4-flash` |
| **Писатель** (`writer`) | Черновик поста и переписывание после замечаний критика | `moonshotai/kimi-k2.7-code` | `deepseek/deepseek-v4-flash` |
| **Критик** (`critic`) | Проверка: нет мата, нет обещаний дохода, все термины объяснены. Ответ `OK` / `FIX: причина` | `deepseek/deepseek-v4-flash` | — |
| **Редактор** (`editor`) | Финальная шлифовка: ритм, крючок, без канцелярита | `deepseek/deepseek-v4-flash` | `qwen/qwen3-next-80b-a3b-thinking` |
| **Художник** (`image`) | Обложка поста 16:9 в брендовом стиле | `recraftv4_1` (GPTunneL, ~7₽) | Pollinations (бесплатно) → Pillow-шаблон (0₽) |

Почему так:

- **Qwen3 Next 80B (thinking)** — «думающая» модель: придумывает темы и подбирает образы для картинок, пишет и исследует. Дорогая для длинных текстов, поэтому только для ideation.
- **Kimi K2.7** — основной писатель: живой язык и длинные связные тексты.
- **DeepSeek V4 Flash** — рабочая лошадка: дешёвая и быстрая, поэтому на ней критик (короткие вердикты), редактор и все запасные цепочки.
- **Recraft v4.1** — генерация в едином фирменном стиле: в запрос передаётся образец `template/brand_bg.png`, картинка наследует палитру и настроение.

Цены, по которым бюджет-гард считает расходы (₽ за 1 млн токенов, вход/выход):

| Модель | Вход | Выход |
|---|---|---|
| `deepseek/deepseek-v4-flash` | 15,75₽ | 31,5₽ |
| `qwen/qwen3-next-80b-a3b-thinking` | 60₽ | 180₽ |
| `moonshotai/kimi-k2.7-code` | 78₽ | 385₽ |
| `recraftv4_1` | ~7₽ за картинку (потолок 10₽) | — |

Актуальные ID и цены сверяйте в панелях провайдеров (`python check_api.py`, `python checkgpttunnel.py`) и поправьте `agent/llm.py` + `agent/budget.py`, если что-то поменялось.

## Основные команды

- `python main.py` — создание и публикация поста
- `python main.py test` — то же самое, но без публикации (пост в консоль)
- `python scheduler.py` — планировщик: посты 13:00/19:00, метрики 22:00, отчёт вс 18:00
- `python run_stats.py` — ручное обновление метрик
- `python run_report.py` — публикация недельного отчёта
- `python finance_report.py` — расходы по моделям за день и за всё время
- `python check_api.py` — проверка LLM API + список моделей
- `python checkgpttunnel.py` — каталог медиа-моделей GPTunneL
- `python check_ref.py` / `python test_img.py` — диагностика Recraft
- `python test_vk.py` / `python test_photo.py` — проверка публикации текста / картинки в ВК

## Troubleshooting

### «Все модели легли»
- Проверьте `SERVERSPACE_BASE_URL` (должен заканчиваться на `/v1`) и `SERVERSPACE_API_KEY`
- `python check_api.py` — убедитесь, что модели из `agent/llm.py` есть в списке; ID должны совпадать символ в символ

### Ошибка VK API
- Проверьте `VK_TOKEN` и `VK_GROUP_ID`; у группового токена должны быть права Wall и Photos
- VK ограничивает частоту запросов — все вызовы уже обёрнуты в retry (3 попытки)
- Групповой токен живёт ограниченное время и отзывается при смене пароля/прав — перевыпустите в панели сообщества

### Картинка не приклеилась к посту
- Фото грузится двумя путями: сначала wall-путь под `VK_USER_TOKEN`, при ошибке — messages-путь под `VK_TOKEN`. Нет `VK_USER_TOKEN` — сразу messages-путь.
- Личные токены тоже отбирают права — проверьте, что у него `wall, photos, offline`
- Посмотрите логи: `[vk] файл весит…`, `[vk] wall-загрузка…`, `[vk] attachment…` — они показывают, какой путь сработал

### Recraft не рисует
- Нет `GPTUNNEL_API_KEY` в `.env` или кончился баланс — `python checkgpttunnel.py` покажет
- Прайс-чек вернул цену выше 10₽ — агент сознательно отказался (потолок `GT_MAX_PRICE` в `agent/image.py`)
- Задача висит дольше 180 секунд — агент не дождался и упал на Pollinations; это норма в часы пик
- Не берёт референс — погоняйте `python check_ref.py`

### Шрифты для запаски на Pillow
- Нужен пакет `pillow` (есть в requirements); на Linux лучше доустановить `dejavu-sans`, иначе запаска ищет `arial.ttf`

## Логирование

Все события логируются с временными метками. Логи включают:

- Ответы LLM (какая модель ответила, какая не вывезла)
- Цену Recraft до заказа и решение по потолку
- Расходы бюджета (с предупреждением при 80% лимита и стопом при пробитии)
- Ошибки VK API с retry-попытками и выбором пути загрузки фото
- Ротацию старых записей (>90 дней)
